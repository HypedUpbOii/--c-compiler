## Fixes of reference implementation

### Array Indexing (Higher dimesions)
The reference implementation generates the wrong TAC for higher dimension array access.
For the following C code :
```c
void main() {
	int arr[30][40][50];
	int i;

	i = arr[23][17][13];

	print i;
}
```
This is the TAC generated by the reference :
```tac
**PROCEDURE: main
**BEGIN: Three Address Code Statements
        temp0 = 23 * 40
        temp1 = temp0 * 4
        temp2 = 17 * 50
        temp3 = temp2 * 4
        temp4 = temp1 + temp3
        temp5 = 13 * 4
        temp6 = temp4 + temp5
        temp7 = arr_[temp6]
        i_ = temp7
        write  i_
**END: Three Address Code Statements
```

The correct TAC code generated by our implementation is :
```tac
**PROCEDURE: main
**BEGIN: Three Address Code Statements
        temp0 = 23 * 40
        temp1 = temp0 + 17
        temp2 = temp1 * 50
        temp3 = temp2 + 13
        temp4 = temp3 * 4
        temp5 = & arr_
        temp7 = temp5 + temp4
        temp8 = * temp7
        i_ = temp8
        write  i_
**END: Three Address Code Statements
```

The 0th index must be multiplied by all of the next dimension sizes in the final offset calculation, but the TAC generated multiplies it only by the next dimension's size. Ideal offset expression (without size multiplication )= ((23 * 40 + 17) * 50 + 13).

We also avoided defining "Array_Access_TAC_Opd" by using & to get the address, adding offset obtained and writing to the correct address using *. This simplified the TAC -> RTL code conversion. 

### Pointer size for floats
Pointers to floats of degree >= 1 in the reference have sizes 8 and use the double variants of instructions. We fixed this so that any pointer occupies only 4 bytes.

RTL code generated by reference :
```rtl
**PROCEDURE: main
**BEGIN: RTL Statements
	load_addr:   f4 <- a_       ;; Result:temp0, Indirect load of a_, Loading the address of a_
	store.d:     ptr_ <- f4
	iLoad.d:     f2 <- 3.00     ;; Loading float number 3.000000
	load.d:      f4 <- ptr_     ;; Loading variable ptr_ into register
	store_ind.d: f4 <- f2
**END: RTL Statements
```

RTL code generated by our implementation :
```rtl 
**PROCEDURE: main
**BEGIN: RTL Statements
	load_addr:	v0 <- a_
	store:		ptr_ <- v0
	iLoad.d:		f2 <- 3.00
	load:		v0 <- ptr_
	store_ind.d:	v0 <- f2
**END: RTL Statements
```

### Global Array Storage
Consider this code :
```c
int arr[3][3][3];
void main() {
	arr[0][1][2] = 3;
	print arr[0][1][2];
}
```
Reference generates asm file :
```asm
	.data
arr_:	.word 0
	.text 			# The .text assembler directive indicates
	.globl main		# The following is the code (as opposed to data)
main:                    # .globl makes main know to the outside of the program.
...
```

Our implementation generates asm file :

```asm
	.data
arr_:	.space 108
	.text
	.globl main
main:
...
```

## Additions on top of reference implementation

### Syntax Additions
We added labels at the beginning and end (wherever necessary) of loops to support break and continue statements. 
We tracked the current context (loop depth, start and exit labels of loops) at the current point in code that are used in these statements.

#### For loop
Syntax of for loop
```c
for (<init_stmt>; <boolean_expr>; <update_stmt>;) {
    ...
}
```
Also works with a singular statement in the body :
```c
for (<init_stmt>; <boolean_expr>; <update_stmt>)
    <stmt>;
```

#### Break statement
Break statement allows to break out of the nearest loop it is contained in.
Syntax of break statement :
```c
while (...) {
    ...
    while (...) {
        ...
        break;
        ...
    }
    // <- control shifts here
    ...
}
```

#### Continue statement
Continue statement allows the nearest loop it is contained in, to skip to the next iteration.
Syntax of continue statement :
```c
while (...) {
    ...
    while (...) { // <- control shifts here
        ...
        continue;
        ...
    }
    ...
}

```

#### Pointers allowed as function parameters
Example code to swap numbers :
```c
void swap(int * a, int * b) {
    int temp;
    temp = *a;
    *a = *b;
    *b = temp;
}

void main() {
    int a, b;
    int *p, *q;

    p = &a;
    q = &b;

    a = 5;
    b = 10;

    print "Initial values a = ";
    print a;
    print " , b = ";
    print b;
    print "\n";

    swap(p, q);

    print "Final values a = ";
    print a;
    print " , b = ";
    print b;
    print "\n";

}
```

### Unreachable code elimination
We removed all the TAC statements that are not reachable from the start.

Consider this code :
```c
int main() {
	int a, b;

	a = 1;
	print a;

	return 0;
    // this segment is unreachable
	b = 1;
	print b;
}
```

Reference generates TAC code :
```tac
**PROCEDURE: main
**BEGIN: Three Address Code Statements
	a_ = 1
	write  a_
	stemp0 = 0
	goto Label0
	b_ = 1
	write  b_
Label0:
	 return stemp0
**END: Three Address Code Statements
```

Our implementation generates TAC code :
```tac
**PROCEDURE: main
**BEGIN: Three Address Code Statements
	a_ = 1
	write  a_
	stemp0 = 0
	goto Label0
Label0:
	return stemp0
**END: Three Address Code Statements
```
